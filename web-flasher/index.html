Muse Gadget Web Flasher

Flash the open source Muse Gadget firmware onto your ESP32 board straight from the browser, in Chrome or Edge on a desktop computer.

1. Your SDK token

A gadget needs your SDK token to pair. Get it from gadgets.muse.ai (Account > SDK tokens). It's sent to the gadget over USB after installing, and the gadget keeps it through updates. This browser remembers it for next time (forget it).

2. Install

You haven't entered your SDK token yet. You can install without it, but the gadget can't pair until it has one.

Your browser doesn't support Web Serial. Use Chrome or Edge on a desktop computer. Web Serial needs a secure (https) connection.

Keep this tab in front while installing. Updating keeps your pairing, Wi-Fi settings and SDK token; on a first install you can choose to erase the device. When the install is done, close the installer: the page sends your token to the gadget, and then you set it up in the Muse app.
