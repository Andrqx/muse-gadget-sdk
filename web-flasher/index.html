Muse Gadget Web Flasher

Flash the open source Muse Gadget firmware onto your ESP32 board straight from the browser. Plug the board in over USB, pick it below and press Connect.

Your browser doesn't support Web Serial. Use Chrome or Edge on a desktop computer. Web Serial needs a secure (https) connection.

Your SDK token

A gadget needs your SDK token to pair. Get it from gadgets.muse.ai (Account > SDK tokens). Once the install is done, close the installer, paste the token here and send it to the gadget, picking the same port. It goes only to the gadget, over USB, and the gadget keeps it through updates.

Updating keeps your pairing, Wi-Fi settings and SDK token. On a first install you can choose to erase the device. Once the token is in, set the gadget up with the Muse app. Built from main.

Board not showing up? Some boards need you to hold BOOT while plugging in USB to enter download mode.
